# 智驱未来 · 人工智能——新质生产力的核心引擎

数据可视化网站（课程作业）。**用浏览器打开 `index.html` 即可**：无需安装、无需本地服务器、**无需联网**。

## 一、如何打开

| 方式 | 操作 |
| --- | --- |
| 推荐 | 双击 `index.html`，系统会用默认浏览器打开 |
| 指定浏览器 | 右键 `index.html` → 打开方式 → 选择 Chrome / Edge / Firefox |

也可以把整个 `work2` 文件夹拷到 U 盘或另一台电脑，双击 `index.html` 一样能跑（图表库已随包）。

> **离线可用**：图表库 ECharts 已打包在 `vendor/echarts.min.js`（约 1 MB），断网也能显示全部 14 个图表。
> 只有网页字体（思源黑体 / Orbitron）在联网时才会加载，断网会自动回退到系统字体，不影响使用与布局。

## 二、目录结构

```
work2/
├── index.html            # 网站入口（双击这个文件）
├── css/
│   └── style.css         # 暗色科技主题、响应式布局
├── js/
│   ├── data.js           # 全部图表数据（含数据来源注释）
│   ├── charts.js         # 14 个 ECharts 图表
│   └── main.js           # 粒子背景、滚动动效、按钮交互、图表懒加载
└── vendor/
    └── echarts.min.js    # ECharts 5.5.1（本地内置，保障离线可用）
```

## 三、页面里的交互

- **顶部导航**：滚动时自动高亮当前章节，点击平滑跳转；窄屏下变为汉堡菜单。
- **首页按钮**：
  - `开始探索 ↓` / `核心结论`：平滑滚动到对应章节
  - `⛶ 全屏演示`：进入 / 退出全屏，按钮文字随状态切换
- **图表懒加载**：滚动到可视区域才渲染，首次进入更流畅。
- **鼠标移到首屏**：粒子网络会与光标连线。
